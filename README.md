# 🚀 Featured Experience

<div align="center">

## 🤖 Nepali Eco-Chatbot

### My First Major Project

</div>

My **first major project**, developed as a **mentee during a summer camp organized by COSOG Nepal**.

During the camp, I collaborated with my team on the **Nepali Eco-Chatbot** initiative, contributing to different parts of the work and learning how a real project comes together.

The project is a conversational chatbot in **Nepali**, built using **Botpress** and integrated directly with **WhatsApp through the Meta Cloud API**.

It aims to make conservation knowledge more accessible to **farmers, students, and communities** in their own language.

### 🤝 Collaboration

As a mentee, I had the opportunity to **collaborate with my team**, exchange ideas, contribute to different parts of the project, and learn how teamwork works in a real project.

The work included areas such as:

- 🖥️ Server-side development
- ⚙️ Project configuration and workflows
- 🧩 Development and experimentation
- 📊 Presentations and documentation

This experience helped me understand that building a project isn't only about writing code — **communication, collaboration, problem-solving, and teamwork matter too.**
