## 🚀 My First Major Project

### 🤖 Nepali Eco-Chatbot

My **first major project**, developed as a **mentee during a summer camp**.

The project is a conversational chatbot in **Nepali**, built using **Botpress** and integrated with **WhatsApp through the Meta Cloud API**.

It is designed to make conservation knowledge more accessible to **farmers, students, and communities** in their own language.

The idea is to make it easier for people to get answers to everyday conservation questions without having to search through complicated or English-only resources.

#### 🛠️ Project Technologies

`Botpress` • `Meta Cloud API` • `WhatsApp`

🔗 **[View the project →](https://github.com/aadityagaire45/Nepali-eco-chatbot-AG)**
